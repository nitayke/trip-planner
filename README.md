# ✈️ מתכנן הטיול הזוגי שלנו (Trip Planner + AI Assistant)

מערכת מלאה, מודרנית וחינמית לחלוטין (100% Free) לתכנון טיול זוגי, כולל סוכן AI חכם שיודע לקבל הוראות בעברית ולעדכן את כל חלקי המערכת בזמן אמת!

המערכת פועלת ב-**Cloud** (דרך Supabase חינמי ו-Vercel חינמי), כך שהיא **זמינה 24/7 משני הטלפונים שלכם גם כשהמחשב בבית כבוי לחלוטין!**

---

## 🌟 יכולות עיקריות במערכת

1. **לוח זמנים ומסלול יומי (Daily Timeline)**:
   - חלוקה נוחה לפי ימים ותאריכים עם תצוגת קרוסלה
   - פירוט פעילויות, שעות, קטגוריות (אוכל, סיורים, תחבורה, אטרקציות) וקישורים ישירים למפה
   - סימון פעילויות שבוצעו ומעקב התקדמות

2. **ניהול טיסות (Flights)**:
   - כרטיסי עלייה למטוס מעוצבים (Boarding Pass)
   - שדות תעופה, מספרי טיסה, זמני המראה ונחיתה, מספרי כרטיס (PNR), מושבים וכבודה

3. **מלונות ולינה (Hotels & Lodgings)**:
   - פירוט מלונות, דירות Airbnb וריזורטים
   - תאריכי צ'ק-אין וצ'ק-אאוט, חישוב לילות אוטומטי, מספרי אישור וטלפון לקבלה
   - כפתור ניווט ישיר ל-Google Maps / Waze

4. **מעקב תקציב והוצאות (Budget & Expenses)**:
   - תקציב משוער מול הוצאות בפועל
   - חלוקת תשלומים זוגית: מה שולם במשותף, מה שולם ע"י הבעל ומה ע"י האישה
   - חיווי יתרה או חריגה מתקציב

5. **רשימת ציוד ואריזה (Packing Checklist)**:
   - חלוקה לקטגוריות (בגדים, אלקטרוניקה, מסמכים, רפואי)
   - שיוך פריט: "עבורו", "עבורה", או "שנינו יחד"
   - סרגל התקדמות וחגיגת קונפטי כשמסיימים לארוז 100%!

6. **סוכן בינה מלאכותית (Google Gemini AI Assistant)**:
   - צ'אט חי וחכם שמבין עברית חופשית
   - **יכולת הפעלת כלים (Function Calling)**: ה-AI יכול להוסיף פעילויות, להוסיף טיסות, לעדכן מלונות, להוסיף הוצאות ולעדכן את רשימת האריזה ישירות מתוך השיחה!
   - כפתורי הצעות מהירים ורעיונות להמשך המסלול

   \`\`\`bash

## 📱 איך להפעיל 24/7 לטלפונים (כשהמחשב כבוי לגמרי) – 100% חינם!

כדי שאתה ואשתך תוכלו להיכנס מהטלפון בכל מקום בעולם (ובארץ) כשהמחשב כבוי:

### שלב 1: פתיחת מסד נתונים חינמי ב-Supabase (2 דקות)
1. היכנסו ל-[Supabase](https://supabase.com) ולחצו על **Start your project** (חינם לחלוטין).
2. צרו פרויקט חדש (למשל: `our-trip`).
3. בתפריט הצדדי ב-Supabase, היכנסו ל-**SQL Editor**.
4. העתיקו את כל תוכן הקובץ המצורף בפרויקט: \`supabase/schema.sql\`, הדביקו ב-SQL Editor ולחצו על **RUN**. (זה יוצר את כל הטבלאות ברגע).
5. היכנסו ל-**Project Settings -> API** והעתיקו:
   - `Project URL`
   - `anon public key`

### שלב 2: העלאה בחינם ל-Vercel
1. פתחו חשבון ב-[Vercel](https://vercel.com) (חינם לחלוטין).
2. חברו את ה-Repository (או העלו בעזרת `npx vercel`).
3. בהגדרות ה-Environment Variables ב-Vercel, הוסיפו 3 משתנים:
   - `GEMINI_API_KEY` = המפתח שלכם מגוגל
   - `NEXT_PUBLIC_SUPABASE_URL` = ה-Project URL מ-Supabase
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = ה-anon key מ-Supabase
4. לחצו **Deploy**.

### שלב 3: התקנה בטלפונים
1. פתחו את הכתובת של Vercel בדפדפן בטלפון (אייפון / אנדרואיד).
2. באייפון (Safari): לחצו על כפתור השיתוף בתחתית -> **״הוסף למסך הבית״ (Add to Home Screen)**.
3. באנדרואיד (Chrome): לחצו על 3 הנקודות -> **״התקן אפליקציה״ / ״הוסף למסך הבית״**.
4. מעכשיו האפליקציה נמצאת אצל שניכם במסך הבית כמו אפליקציה לכל דבר, ומסתנכרנת ביניכם בזמן אמת!
